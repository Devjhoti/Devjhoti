## Hi, I'm Devjhoti 👋

I build websites for businesses: manufacturers, hotels, energy companies, agencies and creatives. I work across design, frontend and backend, from a scroll-animated landing page to a full CMS on a Linux VPS.

- 🌐 **Websites that feel alive:** Next.js, React, GSAP, Lenis, Three.js
- 🧩 **Sites clients can run themselves:** Express and PostgreSQL CMS, Supabase, admin panels
- 🤖 **Useful tools:** AI page analysis, in-browser image processing, OCR scrapers
- 🚀 **Shipping:** Vercel, nginx, PM2, Ubuntu VPS
